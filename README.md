# ytm-ios-poc — نسخه آزمایشی برای آیفون

این یک اپ کامل نیست؛ یک **آزمون فنی** است که فقط همان چیزهایی را می‌سنجد که بدون گوشی واقعی
نمی‌شود جوابشان را فهمید:

1. آیا هستهٔ Rust (همان روش ytm-rs: سرچ ناشناس WEB_REMIX + پخش با کلاینت VISIONOS)
   روی iOS کامپایل و اجرا می‌شود؟
2. آیا آدرسی که از YouTube می‌گیریم روی گوشی و از شبکهٔ خودت قابل دانلود است (نه 403 بسته به IP)؟
3. آیا AVPlayer فایل صوتی progressive را پخش می‌کند؟
4. آیا با قفل شدن صفحه صدا ادامه می‌یابد؟
5. آیا کنترل‌های صفحهٔ قفل (Play/Pause و نوار زمان) ظاهر می‌شوند و کار می‌کنند؟
6. اگر شبکه «برش ۱ مگابایتی» را اعمال کند، آیا مسیر HLS جواب می‌دهد؟

هر چه در اپ روی صفحه می‌بینی در یک لاگ متنی ثبت می‌شود؛ همان لاگ جواب این شش سؤال است.

---

## کدام مسیر را استفاده کنیم؟

- **اپ بومی (IPA):** بخش ۱ و ۲ همین راهنما. کنترل کامل، ولی امضای ۷ روزه و تمدید با کابل.
- **نسخهٔ وب روی Netlify:** بدون امضا و بدون تمدید؛ در Safari گوشی باز می‌شود.
  راهنمای کامل و مستقل: [`web/README.md`](web/README.md).

## ۱) ساختن بیلد در GitHub (بدون مک، بدون Xcode)

بیلد iOS فقط روی مک ممکن است، پس از رانر macOS خودِ گیت‌هاب استفاده می‌کنیم.
این پوشه آماده است: `rust/` (هسته)، `app/` (سوایفت‌یو‌آی)، `.github/workflows/build.yml` (بیلد).

**پیش‌نیاز:** یک اکانت GitHub (رایگان). کد از قبل در مخزن
`https://github.com/Monfaredz/ytrtm` روی شاخهٔ `main` است؛ نیازی به commit دستی نیست.

1. در سایت GitHub، صفحهٔ همین مخزن → تب **Actions**.
2. اگر پیام «Workflows aren’t being run on this repository» آمد، دکمهٔ
   **I understand my workflows, go ahead and enable them** را بزن.
3. در ستون چپ روی **build-ipa** کلیک کن → دکمهٔ **Run workflow** (سمت راست) → **Run workflow**.
4. حدود ۱۰ تا ۱۵ دقیقه صبر کن (اولین اجرا کندتر است). صفحه را رفرش کن؛
   یک ردیف با علامت زرد/سبز ظاهر می‌شود.
5. اگر سبز شد: روی همان ردیف کلیک کن → پایین صفحه بخش **Artifacts** →
   **YtmPoC-ipa** را دانلود کن → فایل zip را باز کن → داخلش **YtmPoC.ipa** است.
6. اگر قرمز شد: روی ردیف کلیک کن → مرحلهٔ قرمز → متن خطا را کامل کپی کن و برایم بفرست.
   (شکست بیلد هم اطلاعات است؛ حدس نمی‌زنیم.)

برای تغییرهای بعدی: GitHub Desktop → **Add local repository** → مسیر این پوشه →
**Summary** → **Commit to main** → **Push origin**. اگر فقط فایل‌های `web/` عوض شوند،
بیلد IPA دوباره اجرا نمی‌شود (فیلتر مسیر در ورک‌فلو).

## ۲) نصب روی آیفون با اکانت رایگان اپل

**محدودیت‌ها را قبل از شروع بدان:** با Apple ID رایگان، اپ **۷ روز** کار می‌کند و بعد باید
دوباره امضا شود؛ هم‌زمان حداکثر **۳ اپ** امضاشده داری و هفته‌ای **۱۰ App ID**. اپ روی گوشی
می‌ماند ولی تا امضای تازه باز نمی‌شود. برای استفادهٔ دائمی باید هر هفته با کابل وصل کنی و
دوباره Sign کنی (یا بعداً سراغ AltStore/SideStore برویم).

1. روی ویندوز **Sideloadly** را از `sideloadly.io` نصب کن.
2. **Apple Devices** را از Microsoft Store نصب کن (یا iTunes از سایت اپل). این‌ها درایور
   ارتباط با آیفون را می‌آورند.
3. آیفون را با کابل وصل کن؛ روی گوشی **Trust** را بزن.
4. Sideloadly را باز کن. فایل **YtmPoC.ipa** را داخل پنجره‌اش بکش.
5. در کادر **Apple ID** یک **Apple ID جداگانه و تازه** بنویس (اکانت اصلی‌ات را استفاده نکن).
   من هیچ‌وقت رمز یا کد دو مرحله‌ای نمی‌خواهم؛ این‌ها را فقط خودت در Sideloadly وارد می‌کنی.
6. **Start** را بزن. اگر کد دو مرحله‌ای خواست، همان‌جا وارد کن. چند دقیقه صبر کن.
7. روی آیفون: **Settings → General → VPN & Device Management** → زیر Developer App
   نام اپل‌آی‌دی‌ات را بزن → **Trust**.
8. آیکون **YtmPoC** روی صفحهٔ اصلی ظاهر می‌شود.

اگر Sideloadly خطای امضا داد یا آیفون را پیدا نکرد، متن خطا را بفرست؛
معمولاً به نسخهٔ Apple Devices یا App ID تکراری مربوط است و حل‌شدنی است.

## ۳) چیزی که در گوشی تست می‌کنیم

1. در کادر جست‌وجو یک آهنگ بنویس (مثلاً `blinding lights`) → **Search**.
   زیر آن چند کارت نتیجه می‌آید. اگر آمد، یعنی InnerTube ناشناس کار می‌کند.
2. یک کارت را بزن. لاگ باید چیزی شبیه این نشان دهد:
   `resolved: itag 140 from rr?.googlevideo.com ipbits=0 expire=…`
   و بعد `probe 1 KiB: {"status":200,"bytes":1024,…}`.
   - `status 200` یعنی آدرس از شبکهٔ گوشی قابل خواندن است.
   - `status 403` یعنی آدرس به IP دیگری بسته شده (مثلاً VPN عوض شده یا اپراتور CGNAT است).
3. **Play** را بزن. اگر صدا آمد، سؤال اصلی «پخش بدون بک‌اند» جواب مثبت است.
4. صفحه را قفل کن. صدا باید ادامه دهد و در **Control Center** و صفحهٔ قفل، عنوان آهنگ و
   دکمهٔ Pause/Play دیده شود. دکمه‌ها را از همان‌جا امتحان کن.
5. اگر پخش شروع شد ولی حدود یک مگابایت بعد قطع شد (لاگ `item failed` می‌دهد):
   سوییچ **HLS** را روشن کن و دوباره **Play** بزن. این مسیر، همان جایگزین ytm-rs برای
   شبکه‌هایی است که فایل progressive را می‌برند.
6. در پایان **Copy log** را بزن و متن لاگ را برایم بفرست. لاگ **هیچ چیز حساسی ندارد**:
   نه آدرس امضاشدهٔ کامل، نه اکانت، نه رمز؛ فقط itag، نام هاست، ipbits، expire، نتیجهٔ probe
   و وضعیت پخش.

## ۴) معنی نتیجه‌ها

- **سرچ نتیجه داد + probe=200 + صدا پخش شد + قفل صفحه ادامه داد** → ستون اصلی اپ روی iOS
  بدون هیچ سرور شخصی می‌ایستد. قدم بعدی، پورت بخش‌های بزرگ‌تر (صف، لایک، لیریکس) است.
- **سرچ نتیجه داد ولی probe=403** → مشکل شبکه است: IP آدرس با IP لحظهٔ resolve یکی نیست.
  با VPN ثابت تست کن؛ یا باید در اپ URL را دوباره روی همان لحظهٔ پخش بسازیم (قابل حل).
- **پخش شروع شد ولی حدود ۱MiB قطع شد** → همان آزمایش گوگل؛ جوابش HLS است (در اپ هست).
- **resolve جواب داد ولی `no plain URL`** → کلاینت visionOS برای این شبکه/آهنگ URL ساده نداده؛
  نسخهٔ دسکتاپ این را با حل‌کنندهٔ امضا (jsc.rs) و yt-dlp دور می‌زند که روی iOS ممکن نیست.
  این تنها ریسک واقعی پورت است و تست نشانش می‌دهد.
- **`request failed` در لاگ** → DNS/شبکهٔ گوشی به YouTube دسترسی ندارد (همان چیزی که
  روی کامپیوتر اینجا دیدیم). با VPN روشن تست کن.

## ۵) چه چیزی در این نسخه نیست (عمداً)

اکانت گوگل، صف، پلی‌لیست، لایک، لیریکس، دانلود، Jam، تم‌ها و رابط اصلی اپ دسکتاپ
در این آزمایش نیستند. این نسخه فقط لبهٔ پرریسک را می‌سنجد: «سرچ + استخراج URL + پخش +
پس‌زمینه». اگر این لبه ایستاد، معماری سوایفت‌یو‌آی + هستهٔ Rust (که در گزارش
`ios-feasibility.md` انتخاب شد) روی همین پایه ساخته می‌شود.

## ۶) یادداشت حقوقی

این پروژه برای استفادهٔ شخصی و آزمایشی است، مثل خود ytm-rs که GPL و بدون دورزدن DRM است.
YouTube Music شرایط استفادهٔ خودش را دارد و این روش (InnerTube ناشناس) خارج از قرارداد
رسمی آن است؛ احتمال تغییر و بسته‌شدنش همیشگی است و برای همین، هستهٔ مشترک با ytm-rs
نگه داشته شده تا لایه‌های جایگزین (HLS، کلاینت‌های دیگر) جدا اضافه شوند.
